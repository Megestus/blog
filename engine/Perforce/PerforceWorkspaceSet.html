PerforceWrokspaceSet

Megestus2024/9/22PerforcePerforce

记一下workspace设置

Basic

workspace name 的名称结构默认是 用户名+电脑系统名称+编号

Advanced

File Options 文件选项:

Allwrite: leave all workspace files writeable when getting revisions
全可写：获取修订版时保留所有工作区文件的可写权限

Clobber: overwrite writeable workspace files when getting revisions
覆盖：获取修订版时覆盖可写的工作区文件

Compress: speed up slow connections by compressing files when submitting or getting revisions
压缩：提交或获取修订版时通过压缩文件来加速慢速连接

Modtime: set file modification times to what they were in the submitter's workspace
修改时间：设置文件修改时间为提交者工作区中的时间

Rmdir: delete workspace directories when empty
删除空目录：删除空的工作区目录

Altsync: only get file metadata when getting revisions
备选同步：获取修订版时仅获取文件元数据

Line ending characters for text files: Local: defaults to the current operating system
文本文件的行结束字符：本地，默认为当前操作系统

On submit: Revert unchanged files Check out submitted files after submit
在提交时：恢复未更改的文件 提交后签出已提交的文件

Client type: Writeable Eligible for backup - server tracking in central location
客户端类型：可写的 符合备份条件-服务器在中心位置进行跟踪

Automatically get all revisions
自动获取所有修订版
