Linux Symbolic Link

Megestus2024/7/1LinuxLinuxdocker
  1. 软连接（Symbolic Link）：
    • 软连接是一种特殊的文件，它包含了指向另一个文件或目录的路径。类似于创建快捷方式，但在操作系统级别上更强大。
    • 通过软连接，您可以在不复制文件的情况下在不同位置访问相同的文件或目录。

  1. mklink 命令：

    • mklink 是 Windows 系统中用于创建链接的命令。
    • 命令语法如下：
      MKLINK [/D] | [/H] | [/J] Link Target
      • /D：创建目录符号链接。默认情况下，它会创建文件符号链接。
      • /H：创建硬链接而不是符号链接。
      • /J：创建目录联接。
      • Link：指定新的符号链接名称。
      • Target：指定新链接引用的路径（可以是相对路径或绝对路径）。

  2. 使用例子：

    • 假设您想在当前路径下创建一个名为 Art 的目录符号链接，指向自定义磁盘位置 E:\Zoroot\Art，您可以执行以下命令：
      mklink /D Art E:\Zoroot\Art
      这将在当前路径下创建一个名为 Art 的目录符号链接，使其指向 E:\Zoroot\Art 目录。

创建软连接的方法需要使用下面的命令：

ln -s [源文件或目录] [软链接文件或目录]

例如，如果要在当前路径创建一个软链接test引向/var/www/test文件夹，可以执行以下命令：

ln -s /var/www/test test

如果需要修改软链接指向的新路径，可以使用以下命令：

ln -snf [新的源文件或目录] [目标文件或目录]

这将会修改原有的链接地址为新的地址。⁴

常用参数：

  • -f: 链接时先将与目标同档名的文件删除
  • -d: 允许系统管理者硬链接自己的目录
  • -i: 在删除与目标同档名的文件时先进行询问
  • -n: 在进行软连接时，将目标视为一般的文件
  • -s: 进行软链接（symbolic link）
  • -v: 在链接之前显示其档名
